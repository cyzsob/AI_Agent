项目：卓易智融                AI应用开发工程师         时间：2026年1月-7月
项目描述：是一个面向与企业级的AI智能办公应用
技术栈：AG-UI、A2UI、MCP、FunctionCall、Vue 3、TypeScript
负责模块：聊天模块、消息推送、UI 布局和设计
技术描述
1. 加密使用 ChaCha20-Poly1305 算法，确保用户消息和敏感数据在传输和存储中的机密性与完整性。
2. 聊天框中的文件渲染采用接口"代理下载/预览"模式，通过鉴权中间件验证身份后，将服务端文件流转为可预览的流式内容，支持图片、文档等多格式在线预览。
3. 聊天模块集成 AG-UI 协议，基于 SSE（Server-Sent Events）实现流式对话：发送请求后逐 token 接收 LLM 回答，前端实时展示打字机效果，提升交互体验。
4. 消息推送通过 UMeng（友盟）服务商实现，支持多端离线消息推送与通知栏展示。
5. UI 布局和渲染基于 A2UI 框架实现，采用 Stitches 样式方案，支持 AI 生成的富 UI 组件渲染（卡片、列表、表单等），结合 CSS 变量体系实现亮/暗色主题适配。
6. 使用 MCP（Model Context Protocol）与 FunctionCall 机制，实现 LLM 与外部工具的安全交互调用。
7. 多轮对话：实现基于上下文的连续多轮对话能力，维护对话历史会话，支持追问、纠错与上下文关联理解，确保对话的连贯性与用户体验。
8. 记忆存储、压缩与过期技术：采用分层记忆存储机制，结合上下文压缩算法减少 Token 占用，并通过 TTL（Time-To-Live）过期策略自动清理历史记忆，平衡对话质量与存储成本。

项目描述：基于LangChain和LangGraph框架开发的RAG知识库问答系统
技术栈：LangChain、LangGraph、DeepSeek 、FastAPI、AG-UI协议、MCP、 RapidOCR、GLM-4V、Vue 3、TypeScript、A2UI协议
主要职责：
1.多Agent智能编排：基于 LangGraph 构建 Supervisor 多 Agent 架构，协调 Agent 根据用户意图路由分发至专业 Worker，支持复杂任务的分解执行与多轮对话。
2.混合检索优化：采用 PGVector 向量与 BM25 关键词双路并行召回，通过 RRF 融合算法合并多路检索候选列表，并引入 Cross-Encoder 模型进行二次精细化重排，显著提升检索召回准确率与大模型上下文质量。
3.流式对话与协议集成：基于 FastAPI + SSE 集成 AG-UI 协议，实现逐 token 流式对话输出，透传工具调用与完成事件，提升交互实时性与开发可扩展性。
4.文档解析与增量入库：RAG支持 TXT/PDF/DOCX 多格式文档解析，采用 PyMuPDF + RapidOCR 混合解析方案，基于 sha256 文件指纹实现增量入库，支撑知识库的高效构建与持续更新。
5.工具自动发现与扩展：通过 MCP 协议自动发现外部工具，封装为 LangChain 工具注入 Agent，实现配置驱动的即插即用扩展，已接入 Gitee 仓库能力。
6.会话管理与查询优化：基于 threadId 实现多轮会话管理，采用 tiktoken 精确计数进行上下文滑动裁剪，并集成查询改写策略提升检索准确率。
7.多模态图片问答：用户上传图片经智谱 GLM-4V 视觉模型生成文字描述，合并进入 RAG 检索链路，实现多模态图片问答能力。
8.前端交互开发：基于 Vue 3 + TypeScript + Vite 构建前端，渲染 AI 返回的结构化 JSON UI，支持亮/暗色主题切换。
